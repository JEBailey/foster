Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Random-source contracts and unbiased integer sampling.

Range bounds are half-open. Invalid ranges and source failures return RandomError. The requested width must fit the source's advertised range. Use seeded generators for reproducibility and SystemRandom for operating-system entropy.

RandomSourcepublic

A stateful source of uniformly distributed nonnegative integers.

next must return a value in the inclusive range from zero through maximum. Every value in that range must be equally likely. Source failure is explicit so host entropy and deterministic generators share one contract without hiding environmental errors.

Required methods

  • next
    Returns the next uniformly distributed source value.
  • maximum
    Returns the inclusive maximum value produced by `next`.

below_withfunctionpublic

pub func below_with(source: RandomSource, count: Int) -> Result<Int, RandomError> [mut source]

Draws an unbiased integer in [0, count) and advances source. Requires 1 <= count <= source.maximum() + 1 and a representable source capacity. Invalid parameters, out-of-contract source values, and source failures return RandomError.
