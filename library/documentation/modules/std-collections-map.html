How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Associative collection contracts and insertion-ordered list maps.

Map<K, V> defines the shared API. Map.empty constructs ListMap, whose key searches are linear. Use std.collections.hash_map for hashed lookup. borrow returns a reference; remove transfers a value and preserves the map. put consumes and returns the updated collection. Require MapLookup<K, V> for borrowing a value or KeyMembership for testing keys when the consumer does not need the full collection and update contract.

Mappublic

An associative collection with unique keys and implementation-defined iteration order. Lookup borrows the stored value. Removal mutates the map and transfers the selected value. put consumes and returns the concrete implementation; membership checks borrow it.

Contracts

  • KeyMembership<K>

Required methods

  • remove
    Removes and returns the owned value, preserving all other entries; absent keys return `None`.

    Consumes the map, `key`, and `value`, returning the updated concrete implementation. Replaces an equal key and releases its previous entry; iteration order depends on the implementation.
  • keys
    Consumes the map and returns its keys in iteration order.
