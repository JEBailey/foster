How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Binary64 encoding, mathematics, formatting, and comparison-based queries.

Angles use radians. Square root and trigonometric methods use backend math operations and leave their inputs usable. Domain errors return NaN rather than failing execution. Trigonometric precision can vary across platforms and builds.

These helpers use ordinary floating-point comparisons. In particular, compare returns Equal when neither operand compares less or greater, including NaN; it is not an IEEE total ordering. See each method's NaN and signed-zero behavior.

Supports Copy: copying preserves the source and returns an independent scalar value.

Float.atan2functionpublic

pub func atan2(self: Float, x: Float) -> Float

Returns the angle of (x, self) in radians in [-pi, pi], leaving both inputs usable. Call y.atan2(x); positive angles turn counterclockwise from the positive x axis. A NaN input returns NaN with unspecified sign and payload bits. For signed-zero y, returns y when x has a positive sign, or pi with y's sign otherwise. This includes all four combinations of signed zeros. Nonzero y with zero x returns pi/2 with y's sign. Infinite y with finite x does the same. Finite y with positive infinite x returns zero with y's sign; negative infinite x returns pi with y's sign. When both are infinite, returns pi/4 for positive x or 3*pi/4 for negative x, with y's sign. Uses platform math precision; finite results may vary in their last bits.

pub func cos(self: Float) -> Float

Returns the cosine of self radians without consuming it. Finite inputs produce values in [-1, 1]; either signed zero returns 1.0. Either infinity or NaN returns NaN, with unspecified sign and payload bits. Uses platform math precision; results need not be bit-identical across targets or builds.

Float.sqrtfunctionpublic

pub func sqrt(self: Float) -> Float

Returns the correctly rounded binary64 square root, leaving self unchanged. Nonnegative finite inputs produce nonnegative roots. Preserves both signed zeros and positive infinity. Negative nonzero inputs, negative infinity, and NaN return NaN. NaN sign and payload bits are unspecified; domain errors do not stop execution.
