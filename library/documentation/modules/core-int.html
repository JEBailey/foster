How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Signed integer helpers, decimal formatting, and eager ranges.

Ranges materialize a List<Int> and exclude the upper endpoint. Arithmetic uses Foster's Int operations; these helpers do not provide arbitrary-precision results. See individual methods for nonpositive exponents and division preconditions.

Supports Copy: copying preserves the source and returns an independent scalar value.

Int.absolutefunctionpublic

pub func absolute(self: Int) -> Int

Returns the distance from zero, ignoring the sign of this integer.

Negative values become positive. Zero and positive values stay the same. The method returns an Int and leaves self unchanged; no move is needed.

import core.int

func main() -> Int {
    let offset = -7
    assert(offset.absolute() == 7)
    assert(offset == -7)
    assert(0.absolute() == 0)
    assert(7.absolute() == 7)
    0
}

Do not pass -9223372036854775808, the smallest signed 64-bit integer. Its positive counterpart, 9223372036854775808, exceeds the largest Int. This method does not return an Option or Result for that case; callers must exclude it before calling.

Int.fromfunctionpublic

pub func from(value: Float) -> Result<Int, IntConversionError>

Truncates a Float toward zero, preserving the input. Returns NotFinite for NaN or infinity, or OutOfRange when the result cannot fit Int. Both signed zeros convert to zero. No saturation or wrapping is performed.
