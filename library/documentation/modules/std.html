    Overview

    How to read this reference

    Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

    Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

    Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

    Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

    Collections, algorithms, and host services for Foster applications.

    std builds on the core library. It provides reusable ways to process values and interact with the outside world: iterate a collection, read a file, exchange bytes over TCP, measure elapsed time, or generate random values. Many operations are written in Foster; operating-system services pass through the runtime's host boundary.

    Choosing an API

    Import a specific module, such as import std.time; importing std does not import all its children. Module functions use module::function(...), while operations on a value use value.method(...).

    A contract describes what a value can do without choosing its storage. For example, Map<K, V> describes map operations; ListMap and HashMap provide different implementations. Choose a concrete implementation for construction and a contract when an algorithm should accept several implementations. Require only the operations the algorithm uses: Sized for length and emptiness, MapLookup<K, V> for borrowed lookup, KeyMembership<K> or Membership<T> for presence checks, and Connector<C> or ListenerProvider<L> for one network role. Collection, Map, Set, and NetworkProvider compose these smaller contracts.

    Collection operations may borrow their input, consume it, or produce a snapshot. Iterator pipelines defer element work until they are advanced. Read the method's effects before reusing a collection or retaining references into it.

    Host operations can fail because a file is missing, a connection closes, or a provider denies access. Fallible APIs return typed Result values; handle the error or propagate it with try. Stream operations can make partial progress before failure. A path or URI describes a location without granting access to it.

    Use a wall clock for timestamps and a monotonic clock for elapsed time. Regional time-zone data is supplied separately by the optional tzdata package. Use a seeded generator for repeatable random sequences and secure randomness for secrets.
