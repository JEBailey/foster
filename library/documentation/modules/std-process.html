How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

The executable name and command-line arguments passed to main.

Accept Arguments as main's parameter to read process inputs. The executable name is separate from values, which contains the user arguments in order. spawn starts a direct child immediately, without invoking a shell. Await its owned handle for captured output. Dropping the handle kills and reaps the child.

Argumentspublic

The command line passed to main.

executable is the path or command used to invoke the program. values contains every following argument in order and does not repeat the executable name. The invocation name is not necessarily an absolute canonical path.

ExitStatuspublic

A child's termination result. Signals may terminate it without an exit code. success records successful termination; code is Some(exit code) when available and None when termination has no numeric exit code.

Processpublic

An owned direct child and its completion future. Cannot be copied or fabricated. Standard input is closed; environment variables are inherited. Cleanup manages the direct child only. Descendants holding output pipes can delay await.

Contracts

  • Future<Result<ProcessOutput, ProcessError>>
