Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Explicit provider contracts for applications. Pass a provider to choose resource implementations; the default adapters use the embedding runtime's HostContext. Clock providers use the existing std.time.Clock contract. Require Connector for outgoing connections and ListenerProvider for binding endpoints. NetworkProvider<C, L> composes both capabilities.

Provided types

Connectorpublic

Supplies outgoing connections, including application-defined stream types. Does not require endpoint binding or a listener type.

Required methods

  • connect
    Connects to an endpoint using this provider's namespace and policy.

FileProviderpublic

Supplies located file resources. Implementations choose their own resource type.

Required methods

  • file
    Resolves a location to a resource without requiring an OS file handle.

ListenerProviderpublic

Supplies bound listeners, including application-defined listener types. Does not require outgoing connections or a connected-stream type.

Required methods

  • listen
    Binds an endpoint using this provider's namespace and policy.

NetworkProviderpublic

Supplies both outgoing connections and bound listeners. Require Connector or ListenerProvider when only one operation is needed.
