Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Stateful iteration, short-circuiting consumers, and lazy pipelines.

Iterable creates independent iterators; Iterator tracks progress through one traversal. Consumers operate on the remaining items and advance the receiver. find and Boolean queries stop once their answer is known. Adaptors take ownership of their input iterator and defer work until next is called.

Provided types

Iterablepublic

A value that can create an independent iterator over a read-only view of its elements.

Required methods

  • iterator
    Creates an iterator positioned before this iterable's first element.

Iteratorpublic

A stateful source that yields one value at a time.

Calling next advances the cursor and may run callbacks that reshape captured storage. The structural effect includes borrowed callback environments; exhaustion returns None.

Required methods

  • next
    Advances this iterator and returns its next value, if one remains.

Functions and methods

  • all?
    Stops pulling as soon as an element fails `predicate`.
  • any?
    Stops pulling as soon as an element satisfies `predicate`.
  • collect
    Collects the remaining elements into one growing list.
  • count
    Counts every remaining element and leaves the iterator exhausted.
  • find
    Returns the first match, leaving later elements unconsumed.
  • fold
    Reduces every remaining element into one owned accumulator, from left to right.
  • for_each
    Calls `action` once for every remaining element without growing the call stack.
  • from_sequence
    Consumes a sequence into an independent stateful iterator.
