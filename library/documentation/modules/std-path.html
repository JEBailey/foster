Host-filesystem paths, lexical composition, and canonicalization.

Path preserves the supplied spelling. Joining and component inspection use host-platform path rules and do not require a path to exist. canonical performs filesystem I/O and returns IoError when resolution fails. A Path is not a URI.

Provided types

Pathpublic

A typed host-filesystem path.

Path preserves the host spelling supplied by the caller. Use canonical when an absolute, normalized path is required.

    Returns this path's final component, or `None` when it is absent.
  • extension
    Returns this path's final extension without its separator.
  • canonical
    Resolves this path through the filesystem to an absolute canonical path. The path must be resolvable; missing paths and host failures return `IoError`. Use lexical composition when the destination does not exist yet.
