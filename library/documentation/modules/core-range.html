Reusable sequence views backed by an owned list.

Range<T> stores supplied values; it is not a lazy numeric interval. Use Int.range to construct consecutive integers. Iterators traverse the stored order.

Provided types

Rangepublic

A reusable sequence view over a bounded list of values.

Construct with Range.from, which takes ownership of the supplied list. This is stored data, not a lazy arithmetic interval; Int.range constructs integer lists. Iteration preserves stored order and creates an independent cursor.
