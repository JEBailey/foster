Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

TOML 1.1 parsing, typed documents, lookup, and rendering.

parse returns a typed document or the first positioned error. Tables and array values can be inspected without converting to untyped host objects. Rendering emits TOML from the value model; it is not a source-preserving editor for comments and original formatting.

TomlDocumentpublic

A complete TOML document whose root is a table.

Fields

  • entries: List<TomlEntry>public

Required methods

  • render
    Consumes the document and renders entries in stored order, using inline tables. Returns an error for duplicate keys or invalid `DateTime` text; comments and formatting are not retained.
  • get
    Consumes the document and `key`, returning the first exact top-level match. Returns `None` when absent; dots in `key` are literal, not path separators.

TomlValuepublic

A scalar, date-time, list, or table value in the TOML data model.

Date, time, and date-time values retain their validated TOML text in the DateTime case so parsing does not depend on a platform clock library. A separating space becomes T; other accepted spellings are retained.
