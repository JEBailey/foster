Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Resource identities separated from access capabilities.

A resource identifier names a location; constructing one does not perform I/O. Readable and writable structural contracts describe the operations supported by a provider. Use std.fs or std.net.tcp for concrete host resources. Choose std.io.Reader or Writer for sequential streams. Readable reads an entire resource; Writable replaces its contents. Matching method signatures alone do not establish these behavioral promises. Sized reports a fallible byte length, unlike std.collections.Sized, which counts elements without an error result.

An owned value that can release its host or provider state deterministically.

Required methods

PositionedReadablepublic

A value supporting bounded binary reads at explicit offsets.

Position belongs to the operation rather than the resource, so callers can share one stable identifier without manufacturing separate reader objects.

Required methods

  • read_at
    Reads at most `maximum` bytes beginning at `offset`.

Resourcepublic

A resource associated with an identifier of the concrete type L.

Keeping L in the contract prevents a file, socket, or future URI-backed provider from losing the kind of identifier with which it was created.

Fields

  • location: Lpublic

ResourceIdentifierpublic

An explicit identifier for a resource provider or target.

The uncommon resource_id member prevents displayable values such as integers from satisfying this contract accidentally merely because they implement as_string.

Required methods

  • resource_id
    Returns the stable textual identifier supplied to the resource provider.

Sizedpublic

Writablepublic
