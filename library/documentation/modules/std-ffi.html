Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Synchronous calls through explicitly compiled C bridges on Windows x86-64.

Binding manifests and native libraries are trusted code. Build them with foster bridge; loading never compiles sources. Arguments and results are copied. C cannot retain input pointers. Reviewed callback/context pairs invoke handlers on their owning thread or queue copied notifications. Resources have one owner, close on scope exit, and cannot cross a remote boundary.

CBridgepublic

A name for an explicitly built bridge. Operations use manifest order, starting at zero. Relative names resolve against FOSTER_BRIDGE_DIR, the current directory, and the executable directory, trying the full name before the bare file name; absolute names load as given. Dependent DLLs resolve beside the bridge or in System32. Opening stores the name; first use resolves it and validates the library ABI. Successful resolutions stay pinned in the thread's bridge registry, even if directories or environment settings change. Failed resolutions are retried on the next call.

Required methods

  • call_with
    Calls C with a callback borrowed for this call only. The adapter is consumed and released before return; its borrowed captures must remain live throughout. One callback/context pair is inserted between the two argument packets.
  • subscribe
    Creates a native registration owning its callback. Retained captures must contain no borrowed references. Queued notifications are delivered by poll_callbacks; direct callbacks run only on the registering thread. The native destructor must unregister and quiesce before returning.
  • call
    Calls a scalar, value-record, void or copied-buffer operation. Rejects constructors.
  • create
    Adopts exactly one non-null C allocation, or returns an error without leaking a partial result. Only constructor operations are accepted.

CResourcepublic

An opaque, non-copyable owner. Private fields prevent fabrication or extracting a C pointer. Receiver calls mutate conservatively. Close errors can retain the resource; deinit always destroys a remaining owner using its cleanup function.

Required methods

  • argument
    Appends this live owner's token. The bridge checks its kind, module, thread, and call lease before resolving it to a native pointer.
  • poll_callbacks
    Delivers queued notifications on the registering thread. Processes only the events pending at entry and returns the first handler/queue failure.
  • check_callbacks
    Reports and clears a callback failure without invoking queued handlers.
  • call
    Calls an operation for this resource type. Errors leave ownership intact.
  • close
    Attempts close. Success destroys the owner; an error preserves or clears it according to the reviewed native close contract. Repeated close succeeds.

A copied result. Scalar conversions check the exact payload length.

Required methods

    Copies one length-prefixed component of a compound result. Every frame is validated, including frames after the requested index. Native pointers never escape through this interface; lengths are bounded by the packet.
