    Overview

    How to read this reference

    Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

    Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

    Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

    Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

    Foundational values and contracts for writing Foster programs.

    core provides the building blocks used throughout the library: numbers, text, lists, optional values, recoverable errors, and contracts for copying, cleanup, and comparison. Start here when choosing how to represent a value. The standard library adds collections, algorithms, and services such as files, networking, clocks, and randomness.

    Using core

    Import the module whose operations you need, such as import core.string. Importing core does not import every child module. Some foundational types are always available to the language; explicit imports expose their full library APIs.

    Option<T> represents a value that may be absent. Result<T, E> represents either a successful value or an error explaining failure. Their individual module pages show how to inspect and transform those outcomes.

    String positions normally count grapheme clusters: the pieces of text a reader sees as characters. A cluster can contain several Unicode scalars and UTF-8 bytes. Choose explicit scalar or byte APIs when those are the units your work needs.

    Read each operation's ownership and boundary rules. For example, copying an element out of a list can fail if the element does not support Copy, and an integer operation can fail if its result does not fit in 64 bits. A familiar method name does not imply automatic copying, clamping, or error recovery.
