Hash-based key-value storage with caller-supplied hashing.

Equal keys must have equal hashes, and hash results must remain stable while keys are stored. Queries have expected constant-time bucket lookup and linear worst-case lookup. Iteration order is unspecified. borrow returns a reference; remove returns the owned value and preserves the table and its other entries.

Provided types

HashMappublic

An unordered associative collection using equality and a caller-supplied hash. Equal keys must have equal, stable hashes. Hashes may be any Int, including negatives. put consumes the table; remove mutates it in place. Iteration uses a snapshot in unspecified bucket order. Lookups are expected O(1), worst-case O(n); growth rehashes all entries.

pub func borrow<K, V>(self: ref[self] HashMap<K, V>, key: K) -> Option<ref[self] V>

Borrows the stored value; absent keys return None. No Copy is required. The reference permits mutation and cannot outlive or survive reshaping the map.

HashMap.putfunctionpublic

pub func put<K, V>(self: consume HashMap<K, V>, key: consume K, value: consume V) -> HashMap<K, V> [mut self.size, mut self.buckets.items]

Consumes the table, key, and value and returns the updated table. Replaces an equal key's entry without changing length; new keys may trigger rehashing. Replaced entries are released. Iteration order is not preserved.

HashMap.removefunctionpublic

pub func remove<K, V>(self: HashMap<K, V>, key: K) -> Option<V> [mut self.buckets.items, mut self.size]

Removes and returns the owned value, leaving other colliding entries and the hasher intact. An absent key returns None and leaves the map unchanged. Values need not support Copy.
