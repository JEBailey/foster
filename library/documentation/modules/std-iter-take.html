A lazy upper bound on the number of yielded items.

take owns its source. Once the requested count is reached it returns None without requesting another source item. Nonpositive counts yield no items.

Iterator.takefunctionpublic

pub func take<T>(self: consume Iterator<T>, amount: Int) -> Iterator<T>

Consumes this iterator and lazily yields at most amount remaining elements. Nonpositive amounts never pull the source; reaching the limit makes no extra source call.
