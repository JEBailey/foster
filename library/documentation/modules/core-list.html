How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Ordered homogeneous collections and eager collection algorithms.

Indexes are zero-based. at distinguishes out-of-bounds access from an element that cannot be copied; first and last collapse both cases to None. borrow returns a reference; remove transfers an element and preserves the list. Borrowing reads preserve the list. Consuming updates return the resulting list. Use std.iter adaptors when intermediate collection allocation is unnecessary.

Algorithms that return owned elements may copy them even though the receiver is borrowed. Their public comments state which elements must support Copy. Use borrow or remove when elements do not implement Copy.

import core.list.List
import core.option.Option

type Item = { value: Int }

func main() -> Int {
    let numbers = [1, 2, 3]
    let selected = numbers.filter((value: Int) -> value > 1)
    assert(selected.first() == Option.Some(2))
    assert(numbers.first() == Option.Some(1))

    // Item has no copy method; remove transfers it instead of copying it.
    let items = [Item { value: 42 }]
    let removed = items.remove(0)
    assert(items.length == 0)
    branch removed {
        Option.Some(item) -> { assert(item.value == 42) }
        Option.None -> { assert(false) }
    }
    0
}

An ordered value collection backed by private copy-on-write contiguous storage.

Required methods

  • push
    Appends `value` to this list in place.
  • append
    Returns this list with `value` appended.
  • at
    Copies the element at a zero-based index without removing it. Returns `OutOfBounds` for an invalid index and `NotCopyable` if copying is unsupported. Bounds are checked first.
  • contains?
    Returns whether this list contains `expected`.
  • first
    Copies the first element, or returns `None` when it is absent or not copyable.
  • last
    Copies the final element, or returns `None` when it is absent or not copyable.
  • map
    Applies `transform` to every element, from left to right.
  • filter
    Returns independent copies of elements for which `include` evaluates to true. Visits left to right, copying each element before calling `include` once. Asserts if any visited element lacks Copy, even when the predicate would reject it.
  • fold
    Reduces the list from left to right, beginning with `initial`. Copies each element before passing it and the owned accumulator to `combine`. Asserts if an element lacks Copy; an empty list returns `initial` unchanged.
  • find
    Returns an independent copy of the first matching element, or None if none matches. Copies each visited element before calling `predicate`, stopping at the first match. Asserts if a visited element lacks Copy; later elements are not inspected.
  • any?
    Returns whether any element satisfies `predicate`, stopping at the first match. Returns false for an empty list.
  • all?
    Returns whether every element satisfies `predicate`, stopping at the first failure. Returns true for an empty list.
  • reverse
    Builds a reversed list of independent element copies, preserving the source. Asserts if an element lacks Copy. Visits right to left and allocates one result list.
  • concat
    Appends independent copies of every element of `right`, consuming the left list. Asserts if an element of `right` lacks Copy; left elements need no copying.
  • borrow
    Borrows the stored element; invalid indexes return None. No Copy is required. The reference permits mutation and cannot outlive or survive reshaping the list.
  • remove
    Removes and returns an owned element, preserving the list and remaining order. Invalid indexes return None without changing the list. Takes O(n) time.
  • slice
    Copies elements in the half-open range `[start, end)`. Asserts unless `0 <= start <= end <= length`; selected elements must support Copy.
  • take
    Copies at most the first `count` elements; a nonpositive count returns an empty list. Asserts if a selected element lacks Copy; preserves the source.
  • drop
    Consumes the list and returns the elements after the first `count` entries. A nonpositive count preserves all elements; a count at least the length returns empty. For an interior count, copies the retained suffix and asserts if it lacks Copy.
  • flat_map
    Maps elements left to right and copies each returned list's elements into one result list. Calls `transform` once per input element. Asserts if a returned element lacks Copy.
  • count
    Counts the elements satisfying `predicate`.
  • none?
    Returns whether no element satisfies `predicate`.
  • reduce
    Combines independent copies left to right, or returns `None` for an empty list. Asserts if an input element lacks Copy. A singleton returns its copy without calling `combine`.
