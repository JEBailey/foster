Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Parsed URI values and resource identification without network access.

Parsing validates the scheme and separates it from the remaining resource text. Authority, query, and fragment are not exposed as separate parsed components. Constructing or inspecting a Uri does not fetch its resource; protocol-specific I/O belongs to the provider that accepts the identifier.

Provided types

Uripublic

A parsed URI resource identifier.

Uri implements ResourceIdentifier but deliberately provides no resource or I/O capability. Protocol providers convert it into their typed locations—such as TcpEndpoint—before creating an appropriate resource implementation.

Uri.parsefunctionpublic

pub func parse(value: consume String) -> Result<Uri, UriError>

Validates an ASCII scheme followed by : and retains the remaining text verbatim. The scheme starts with a letter and then permits letters, digits, +, -, and .. Returns UriError for missing or invalid schemes; it does not validate percent escapes, authorities, paths, queries, or fragments. Scheme spelling is not normalized.
