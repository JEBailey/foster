Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

JSON trees, strict parsing, exact number text, and deterministic serialization.

parse accepts one complete JSON value. Object order is preserved and duplicate decoded keys are rejected. Numbers retain their original spelling and precision; conversion to Int or Float is explicit. Strings are Unicode scalar text: lone UTF-16 surrogate escapes, comments, trailing commas, and a leading BOM are errors. stringify borrows its tree and emits compact JSON; pretty uses two spaces. Both parsing and serialization default to at most 128 nested containers.

JsonErrorpublic

A JSON failure. offset is a zero-based UTF-8 byte offset. line and column are one-based, columns count bytes, and LF starts a new line (including CRLF). Non-source failures use offset -1 and line/column 0. Messages are explanatory, not a stable interface for branching; use kind instead.

JsonNumberpublic

A validated JSON number, stored as exact decimal text without precision loss. Construction validates syntax; exponent and coefficient size are not restricted by machine numeric ranges. copy and text preserve spelling, including -0.

Contracts

  • Copy

  • as_int

  • as_float
