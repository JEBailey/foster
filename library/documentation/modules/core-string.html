Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Immutable Unicode text, UTF-8 cursors, and text construction.

String lengths and slice bounds count Unicode 17.0.0 extended grapheme clusters. Iteration, head/rest, first/last, reversal, and empty-separator splitting also use whole clusters. code_points() and StringCursor provide scalar access. byte_length() and StringCursor checkpoints count UTF-8 bytes. Use a cursor for repeated sequential reads and StringBuilder for incremental output. Case conversion uses Unicode 17.0.0 without normalization or locale tailoring.

A grapheme cluster is a text element that often appears as one character. A scalar is one numbered ingredient of that element; UTF-8 bytes store those ingredients. A letter plus a combining accent therefore counts as one cluster but two scalars. Use length for text elements and byte_length() for storage size. Normalization would make equivalent spellings use a common representation; casing does not perform that extra step. Locale tailoring would adapt rules to a language or region; these methods use Unicode's default rules instead.

import core.string
func main() -> Int {
    let text = "Aé👩‍💻"
    assert(text.length == 3)
    assert(text.scalar_length() == 6)
    assert(text.byte_length() == 15)
    assert(text.slice(1, 2) == "é")
    0
}
