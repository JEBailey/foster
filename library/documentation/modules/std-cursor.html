Overview

How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Checkpointable readers over stable collection snapshots.

Cursor<T> extends Iterator<T>; T is the item type, not the source type. ListCursor offsets count elements and BytesCursor offsets count bytes. StringCursor, provided by core.string, yields scalars but uses UTF-8 byte offsets. Checkpoints carry no source identity: callers must use the same source snapshot. restore validates bounds (and text boundaries); a failed restore does not move. span copies a half-open region without moving the cursor.

import core.string
import core.option
func main() -> Int {
    let reader = StringCursor.from("Aλ🙂")
    assert(reader.next() == Option.Some('A'))
    let start = reader.checkpoint()
    assert(reader.next() == Option.Some('λ'))
    assert(reader.text_span(start, reader.checkpoint()) == Option.Some("λ"))
    assert(reader.restore(start))
    0
}

Cursorpublic

A reader whose checkpoints are offsets in its source (bytes for UTF-8 text). Checkpoints must come from the same source snapshot; this is a caller obligation. Validation rejects invalid offsets but cannot detect an offset from another source.

Contracts

  • Iterator<T>

Required methods

  • peek
    Reads the current item without advancing.
  • checkpoint
    Returns the current source offset.
  • restore
    Restores a valid source offset, leaving the position unchanged on failure.
  • span
    Copies `[start, end)` without changing the position; invalid bounds return `None`. Bounds use the source's offset unit, which can differ from the yielded item type.
