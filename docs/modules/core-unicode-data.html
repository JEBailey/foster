Data tables that tell Foster about Unicode 17.0.0 text.

Unicode gives text elements numeric code points. These tables record facts about those numbers: whether they are letters, how their case changes, and where text can be split. They are lookup data, not fonts or a collection of text to display.

Most programs should use core.string and core.code_point. This module returns packed strings for the core.unicode algorithms; the hexadecimal strings are not user text. Public visibility lets those modules share the tables, but their numeric IDs and packing are internal details. A missing case mapping leaves the input unchanged.

A grapheme cluster is a text element that often looks like one character, such as a letter plus its accent. It can contain several code points. Foster uses these tables to keep those elements together when counting or slicing String values.

Tables are generated from vendored Unicode files. Regenerate with tools/unicode; edit its generator rather than editing table data. See tools/unicode/README.md for maintenance.

categoriesfunctionpublic

pub func categories() -> String

Classifies code points into broad groups such as letters, numbers, punctuation, and marks. The stored numbers identify Foster's GeneralCategory cases. Use CodePoint.category() for named results.

Returns categories as start(6), end(6), value(2) hex records.

extended_pictographicfunctionpublic

pub func extended_pictographic() -> String

Marks code points used by the emoji joining rules, including some reserved positions. This is an input to grapheme segmentation, not a complete test of whether text is an emoji.

Returns extended_pictographic as start(6), end(6), value(2) hex records.

foldfunctionpublic

pub func fold() -> String

Maps case variants to a common form for comparisons that ignore case. Use String.case_fold(); folding is not display capitalization and does not normalize text.

Returns full fold source(6), length(1), three targets(18) hex records.

grapheme_breakfunctionpublic

pub func grapheme_break() -> String

Groups code points by their role in deciding where a text element ends. Foster combines these properties with boundary rules so accents and supported emoji sequences stay together.

Returns grapheme_break as start(6), end(6), value(2) hex records.

pub func indic_conjunct_break() -> String

Identifies consonants, linking characters, and extending marks used in Indic conjunct boundary rules. These rules keep certain connected letter sequences together when Foster splits text into grapheme clusters.

lowerfunctionpublic

pub func lower() -> String

Maps code points to lowercase text. A full mapping can produce more than one code point. String.lower() applies these mappings and the contextual Greek final-sigma rule.

Returns full lower source(6), length(1), three targets(18) hex records.

propertiesfunctionpublic

pub func properties() -> String

Records additional yes/no facts, such as whether a code point is alphabetic or whitespace. Several facts share one numeric bit mask. Prefer CodePoint classification methods to decoding these bits.

Returns properties as start(6), end(6), value(2) hex records.

pub func upper() -> String

Maps code points to uppercase text. For example, the full uppercase mapping of sharp s is SS. Use String.upper() to convert text; this table is not a list of uppercase characters.
