How to read this reference

Green public labels mark accessible declarations; amber private labels mark implementation details. A public type can contain private fields. Visibility is shown for each member independently.

Read fields as value.field and call methods as value.method(), including zero-argument methods. Required methods describe a type's contract; functions and methods list implementations. Overloads share one navigation entry, with a signature and description for each overload.

Signatures show resolved types and effects, including inferred information, and are reference notation rather than copyable declarations. consume transfers ownership: pass an existing owned binding with move. read, mut, and reshape describe access to the named group or path; suspend permits suspension. Check the description for bounds, units, copying, and failure behavior.

Option<T> represents an optional value; Result<T, E> carries success or a typed error. Assertions and execution failures are distinct from returned errors.

Mutable byte construction with immutable snapshots.

Append with push or extend. snapshot preserves the buffer; freeze consumes it and returns Bytes. Capacity and reservation APIs are allocation hints, not guarantees about reserved storage. Negative sizes fail an assertion.

ByteBufferpublic

Mutable byte construction storage.

Capacity is an implementation hint: the Foster implementation reports its current length and accepts reservations without making allocation strategy observable.

Fields

  • value: List<Byte>private

Required methods

  • push
    Appends one byte.
  • extend
    Appends an immutable byte sequence.
  • clear
    Removes every buffered byte.
  • truncate
    Keeps at most the first `length` bytes; a larger length leaves the buffer unchanged. Asserts if `length` is negative.
  • reserve
    Accepts a nonnegative allocation hint; negative values fail an assertion. The current implementation does not reserve storage in advance.
  • freeze
    Consumes the buffer and packs its values into immutable bytes.
  • snapshot
    Copies the current values into immutable bytes.
  • empty?
    Returns whether the buffer contains no bytes.
  • length
    Returns the number of buffered bytes.
  • capacity
    Reports current length without exposing allocation strategy.
