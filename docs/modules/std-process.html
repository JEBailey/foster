The executable name and command-line arguments passed to main.

Accept Arguments as main's parameter to read process inputs. The executable name is separate from values, which contains the user arguments in order. This module does not launch subprocesses.

Provided types

Argumentspublic

The command line passed to main.

executable is the path or command used to invoke the program. values contains every following argument in order and does not repeat the executable name. The invocation name is not necessarily an absolute canonical path.
