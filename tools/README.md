# Foster development tools

- [driver](driver/README.md): embedded Foster implementations of project creation, project management, formatting, and documentation generation.
- [cbind](cbind/README.md): import C headers into typed Foster bindings and a C bridge.
- [unicode](unicode/README.md): offline Unicode table generator written in Foster.
- [tzdata](tzdata/README.md): timezone database generation and reference checks.
- [CI selection](ci/README.md): component routing and repository checks.
- [Profiling examples](profiling/README.md): development-only Rust measurement tools.
- [Integration runner](../tests/README.md): component suites, target selection, and bounded concurrency.

The [benchmark guide](../benchmarks/README.md) indexes repeatable performance
harnesses. Diagnostic experiments and recorded results live in [research](../research/README.md).
